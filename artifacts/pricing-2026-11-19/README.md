# 요금/문서/헤비 사용자 검토 /2026-11-19

PDF3쪽과 상세 docs/pricing-heavy-users-2026-11-19.md는 당시 입력의 고정 보고서다. XLSX는 파란 가정을 편집하는 수식 계산기, JSON/CSV는 원본 계산이다. scripts/calculate-pricing-2026-11-19.py로 외부 API호출 없이 JSON/CSV/XLSX를 재생성한다. 보고서/PDF는 입력을 바꿀 때 별도 갱신해야 한다.

가격/사용량/환율/수수료/인프라/지원 비용은 계획 가정과 실제 비용을 구분한다. 인건비 전 운영 잔액을 최종 순이익으로 사용하지 않는다. 새 플랜별 실제 예산과 결제는 활성화하지 않았다.
