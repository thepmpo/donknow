# 실제 운영자 조회 어드민

## 사용 흐름

실제 운영 화면은 /admin,예시 구조는 /admin-preview다. 기존 덕 계정으로 로그인한다. 서버의 DUCK_ADMIN_EMAILS에 정확히 지정되어있고 이메일 인증을 마친 계정만 들어간다. 회원을ID/이메일로검색→선택→기본정보/이용권/결제/연결·동기화/AI사용량을확인한다. 왼쪽운영현황/회원목록/운영기록은전체운영자조회이고다른메뉴는선택한회원이있어야보인다.

## 실제 자료와 경계

- 회원:users의id,email,created_at,email_verified_at만조회.25개단위와총수·다음페이지.
- 이용권:기존accountAccess의현재무료Pro정책을이용한다. 개별발급ledger는없어시작일을가입일로만들지않는다. 만료설정없음·현재정책무료제공으로표시한다.
- 결제:PG/결제ledger가없다. items=[]·available=false로표시하고실제매출/0원결제/가입일결제를꾸미지않는다. ai_funding도결제영수증이아니다.
- Todo:json_extract를쓴총수/완료수만반환한다. 제목/메모/내용은조회응답에없다.
- 연결:integrations의provider/label/updated_at만조회한다. payload를복호화하거나외부공급자에접속하지않는다. updated_at은연결정보갱신일이지동기화성공시각이아니다.
- 동기화:source_edit_outbox/task_sync의상태별건수만반환한다. 원본/에러원문·토큰은없고작업을재실행하지않는다.
- AI:기존월별funding/costs와agent_usage합계. 사용·예약원가와예산,기록된에이전트대화를표시한다. 전체모델호출의완전한집계/연결성공진단이아니다. 무료Pro와AI자금은별도다.
- 감사:새admin_access_log에운영자ID/고정조회종류/대상회원ID/시각만저장한다. 검색문자열·본문·토큰은저장하지않는다. 사용자삭제시FK SET NULL로대상/운영자ID도익명화한다.

## 서버·브라우저 보안

GET /api/admin/session,overview,members,members/:id,audit만있다. 기존쿠키/Bearer세션확인후정확한허용이메일+인증을다시검사한다. 브라우저의역할표시/임의헤더/상품값을신뢰하지않는다. 기본허용없음이며환경값파싱이잘못돼도전부차단한다. 모든응답no-store이고쓰기메서드는405다. SQL은매개변수바인딩·검색길이/페이지범위제한·LIKE와일드카드이스케이프·ID검사를쓴다.

/admin의HTML/JS껍데기는공개지만회원정보는포함하지않는다. 실제정보는인증된API에서만온다.로그아웃/401/403에서자료를지우고요청세대/AbortController로늦은결과를버린다.브라우저저장소에운영자토큰·회원목록을저장하지않고출력은escape한다.

현재는조회전용이다. 이용권변경/PG청구·환불/회원권한승격/AI자금지급/연결토큰변경/원본재시도는만들지않았다. 실운영로그인은사용자가보유한기존비밀번호/이메일인증으로수행해야하며이를대신사용하거나비밀번호를요청하지않았다.
