# 별도 관리자 소유자 초기 설정

소유자가 지정한 관리자 주소를 DUCK_ADMIN_EMAILS로 제한하고 서버 비공개 DUCK_ADMIN_INITIAL_PASSWORD로 1회 초기화한다. 이 방법은 소유자의 명시 요청으로 적용한다. 실제 주소와 비밀번호는 소스·공개 문서·로그에 기록하지 않는다.

- admin_accounts에 소유자 활성화 시각을 별도 기록하며 이메일 인증 여부를 조작하지 않는다.
- 초기 비밀번호는 scrypt 해시만 저장한다. 초기 설정 후 환경값을 비운다.
- 임시 로그인 세션은 10분이며 자신의 최소 세션 정보와 비밀번호 변경·로그아웃만 허용한다. 회원·운영 현황·이력 API는 403이다.
- 로그인 직후/새로고침 때 비밀번호 변경 카드만 표시한다. 변경 전 내비게이션과 내부 자료를 렌더링하지 않는다.
- 새 비밀번호는 10~128자이고 확인 입력을 요구한다. 이전 비밀번호와 같을 수 없다. 변경 후 모든 관리자 세션을 폐기하고 새 세션을 발급한다.
- 초기 환경값이 남아 있어도 재시작으로 변경된 비밀번호를 다시 초기화하지 않는다.
- 기존 덕 앱 사용자·비밀번호·세션 및 실제 결제·권한·예산 정책은 변경하지 않는다. 현재 어드민 운영 기능은 조회 전용이다.
- 일반 메일 발송 서비스의 도메인/테스트 수신자 제한은 이 변경과 별개이며 해결됐다고 표시하지 않는다.

검증: test/admin.test.js는 서버 강제 차단, 임시 세션 폐기, 앱 세션 보존, 재시작 후 비밀번호 보존을 검증한다. mobile/e2e/admin-bootstrap.mjs는 합성 계정으로 실제 로컬 서버와 Chromium에서 로그인→변경 전용 화면→새로고침→새 비밀번호→관리 화면→로그아웃을 검증했다. 전체 테스트 448개 중 447개 통과, 1개 기존 제외, 실패 0. 서버/웹 문법 검사 115개 통과.
