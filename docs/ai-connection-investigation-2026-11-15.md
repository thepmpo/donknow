# AI 외부 연결 실진단 — 진행 중

사용자 새 사진은 `AI 서비스에 연결하지 못했어요`로, HTTP 응답 이전 fetch 예외 경로다. 이전 Render503/비JSON 메시지와 구분한다. broad catch가 DNS/TLS/잘못된 헤더 등 실제 원인을 가렸으므로 자유 오류문/키/본문을 기록하지 않고 알려진 원인 코드만 분류한다. 서버 시작 뒤 read-only GET으로 설정 모델 접근 가능 여부를 한 번 확인한다. 사용자 자료나 프롬프트를 보내거나 유료 생성을 실행하지 않는다. 키·모델 환경 문자열 앞뒤 공백은 정리하며 기존 키/계정/서명은 바꾸지 않는다.

이 기록은 진단 배포 단계다. 검사와 웹/서버 반영·실제 모델 접근 결과를 구분한다. 아직 AI 실제 연결 성공·전체 원인 해결을 주장하지 않는다. 캘린더 첫 주 선·전화 숨김·초기 전체 활성화·원본 내용/시간 편집 동기화와 실패 시 덕 채팅 안내/대안을 후속 구현 중이다. 기존 사용자 설정의 명시적 끄기와 시스템 권한을 존중한다.
