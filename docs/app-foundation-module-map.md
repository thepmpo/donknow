모듈JSON의 dependsOn을 먼저 준비한다. 선택 모듈은 필요할 때만 포함한다. 새 앱 교체 항목을 제품 계약 양식에 옮기고 해당 원본/테스트를 읽는다. useTodos·App.tsx·ui.tsx·agent계열 파일의 도메인 결합은 설계서의 책임 분리 순서를 따른다.
