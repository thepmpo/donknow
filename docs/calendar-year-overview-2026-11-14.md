# 연간 달력·월 확대 전환과 개별 롤백

사용자는 첫 이미지인 **연간 달력형**을 선택하고, 일반 iPhone 전체 캘린더 / Duo 선택한 캘린더 영역이라는 전환 설명 후 “일단 구현해봐 그리고 이상하면 연간만 롤백할 수 있어”로 구현을 승인했다. 이전의 년월 ‘답변 대기’는 이 결정으로 대체한다. [기기별 탭 단축](calendar-navigation-2026-11-14.md)·[viewport/캐시](calendar-viewport-2026-11-13.md)는 유지한다.

## 사용자 흐름

1. 캘린더 오른쪽 위 년월 → 작은 달력12개가 있는 연간 보기.
2. 월 선택 → 선택한 위치에서 월간 화면으로 확대. 별도 적용 버튼 없음.
3. ‘월간 보기’/Duo 원형 Back/Escape/Android Back → 현재 월로 복귀. 다른 해를 살펴보기만 했다면 날짜를 바꾸지 않음.
4. 검색·추가·조회 상태·보기/출처/시간대 설정은 **더보기(…)** 안에 유지. 날짜 탐색과 분리.

일반 iPhone의 하단5탭/상단2주 버튼, Duo의 **카메라 열 Today→2주→5탭**과 안전 영역·분할을 보존한다. Duo 연간은 선택한 pane에서만 전환하며 다른 pane의 캘린더/할 일/입력을 바꾸지 않는다. 접힘·세로에서는 하나의 활성 본문을 사용한다. 월/2주는 계속 화면 높이를 채우고 세로 스크롤하지 않는다. 연간은12개월/큰 글자를 위해 세로 스크롤 가능하며 스크롤바를 숨긴다.

## 시안·영상 근거

[선택 이미지](../artifacts/calendar-year-2026-11-14/proposals/selected-year-overview.png), SHA256 `554fb3988080e165dc1e2135c714c502d4e926f885868315e20580d0eb04e14e`. 같은 proposals 폴더의 다른2개는 미선택 이력이다. [Apple 영상/공식 문서 비교](calendar-navigation-review-2026-11-14.md)를 함께 읽는다. 사용자 원본 영상·개인 일정 프레임은 공개하지 않는다.

생성 시안의 잘못된 날짜 숫자·Duo 본문 중복 보기 버튼·외곽 그림자는 새 규격이 아니다. 실제 날짜 계산·기존 공통 제목·카메라 열/분할/Glass 계약이 우선한다. 이번 모션은 영상의 확대·축소 흐름을 참고한 덕 구현이며 Apple 비공개 API/공식 고정 수치를 사용했다는 뜻이 아니다.

## 구현 수치와 상태

| 요소 | 기준 |
| --- | --- |
| 확대·축소 |420ms,cubic(.22,1,.36,1),같은pane 안 실제 타일/본문 좌표 |
| 동작 줄이기·좌표 없음 |120ms페이드,scale1. 다른해/화면밖타일로 잘못 날아가지 않음 |
| 크기 |균일scale=min(타일폭/본문폭,타일높이/본문높이). 글자를 가로/세로로 다르게 늘리지 않음 |
| 미니 달력 |2열·좌우24pt기준,월이름17/25.5·700,날짜10/15. 시작요일 공유·일빨강/토파랑·오늘밑줄/굵기 |
| 해 |1900–2100,경계버튼비활성,그레고리력윤년. 모델명/폭표 하드코딩 없음 |
| 구현 |CalendarYearNavigator.tsx, calendar-year-model.ts, calendar-features.ts. 연결은 CalendarScreen.tsx |

실측 준비 전 짧게 레이아웃을 기다리고 현재 월 근처 **행 시작**으로 스크롤한다. 처음 구현에서 위쪽 월 제목이 잘리던 위치를 실측 헤더/타일 높이로 정정했다. 전환 중 두 번째 선택은 막으며 완료 후 입력을 복원한다. generation으로 중단된 애니메이션·실측 콜백을 무효화한다. 활성 상태/소유자/크기/동작 줄이기 변경 시 과거 좌표를 계속 쓰지 않는다. 기존 Shell key/scope로 계정·서버를 격리한다. 회전·접힘으로 선택월·현재탭·다른pane·입력을 초기화하지 않는다.

월 타일 하나가 하나의 접근 가능한 버튼이다. ‘2026년11월로 이동’처럼 읽고, 작은 날짜 하나하나에 초점을 주지 않는다. 닫으면 년월 트리거로 초점을 복귀한다. VoiceOver/실제 진동은 별도 실기기 검수다. 더보기 시트를 닫아도 탐색 중인 해를 보존한다.

## 데이터와 네트워크

월간 본문·일정 캐시는 유지한다. 연간12개월 숫자는 로컬 계산만 한다. **연간을 열거나 해를 넘기는 것만으로12개월 일정을 미리 조회하지 않는다.** 월을 최종 선택했을 때만 기존 기간 읽기 경로를 사용한다. 원본 수정·발송·OAuth 재승인은 호출하지 않는다. 기존 월간/2주·탭Today/길게누르기·데이터/인증·복구bundle·무료수동빌드정책을 보존한다.

## 연간만 되돌리는 방법

권장: `mobile/src/calendar-features.ts`의 **`yearOverview: true`를 `false`로 변경**한다. 연간 UI/줌/새 더보기 분리가 꺼지고 이전 년·월 선택창/명시적 이동 버튼으로 돌아간다. 월간·2주·탭 단축·캐시·연동·Todo를 되돌리지 않는다. OFF 상태로 별도 웹 번들을 만들고 이전 선택창/월 이동/Today 단축을 실제 검사했다. [OFF 선택창](../artifacts/calendar-year-2026-11-14/rollback-legacy-picker-open.png).

**이미 설치한 아이폰은 롤백 코드로 다시 빌드·업데이트해야 한다.** 서버에서 즉시 바뀌는 스위치가 아니며 앱 삭제·로그아웃·데이터 초기화는 필요 없다. 연간 소스 커밋도 분리한다. 이후 다른 수정이 쌓였을 때 전체 저장소 reset/강제push 대신 이 스위치만 바꾸고 검사·일반 커밋/push한다.
