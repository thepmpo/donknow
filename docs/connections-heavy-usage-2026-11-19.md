# 연결 개수와 헤비 사용량 기준 — 2026-11-19

## 확정한 연결 계산 방식

사용자 정정: **Gmail·캘린더·Google Tasks는 같은 Google 계정이어도 각각 별도 연결**로 센다. OAuth 로그인이나 토큰을 묶어 발급받더라도 요금제의 연결 수는 활성화한 서비스 단위다.

| 구성 | 연결 수 |
|---|---:|
| Gmail1 + Google Calendar1 | 2 |
| Gmail1 + Google Calendar1 + Google Tasks1 | 3 |
| Gmail계정2개 + Google Calendar계정1개 | 3 |
| Gmail1 + Google Calendar1 + Slack워크스페이스1 | 3 |
| 위 구성 + Notion워크스페이스1 + iPhone미리알림1 | 5 |

같은 서비스의 다른 계정/워크스페이스는 별도다. 같은 서비스/같은 계정의 재인증·토큰 갱신은 중복 차감하지 않는다. 한 캘린더 서비스 안의 개별 달력, Slack 채널, Notion 페이지는 추가 연결로 세지 않고 자료/작업 사용량으로 관리하는 **설계안**이다. 등록에 실패하거나 사용자가 인증을 취소한 새 연결은 슬롯을 쓰지 않는다. 기존 자료나 연결을 자동 해제하지 않는다.

## 개수 제안 — 아직 확정 숫자가 아님

- 라이트16,900원: **연결3개 제안**. 예:Gmail·Google Calendar·Slack.
- 프로49,900원: **연결10개 제안**. 직접 AI채팅과 확대 사용량 포함.
- 비즈니스:서비스/계정/팀 사용량을 상담 후 협의.
- 무료의 연결 개수는 이번 요청에서 새로 확정하지 않는다. 기존 직접 작성·자료 가져오기를 임의로 제한하지 않는다.

사용자는 연결 개수 제한을 두자는 방향과 서비스별 별도 계산을 확정했다. 3개/10개는 작업자의 제안이므로 새 결제나 실제 계정에 강제 적용하지 않는다. 고객용 수치를 게시/집행하기 전에 확정해야 한다. 현재 사이트의 확정 가격/기능표는 유지하고 이번 개수는 이 문서에 설계안으로 남긴다.

## 헤비 사용자는 무엇인가

**여기서는 AI가 처리한 전체 작업량이 많은 사용자를 말한다.** 연결 개수나 채팅 횟수만으로 정하지 않는다. 긴 원문 읽기·새 변경 확인·브리핑·문서 초안/수정·검색/실행 도구·직접 대화를 합산한다. 연결1개라도 매일 수천 건의 원문을 처리하면 연결10개를 가볍게 쓰는 사용자보다 비용이 클 수 있다.

운영 판단 기준 제안:

1. 월 공통 AI 제공량의 **80%부터 사용량 안내**, 100%에서 유료 AI처리를 중지한다. 80%는 비용을 추가 청구하거나 기능을 갑자기 막는 기준이 아니다.
2. 짧은 채팅을 매일20회 안팎 지속하거나, 긴 복잡 문서를 일주일3건 이상 반복하는 패턴은 프로에서 집중 사용으로 볼 수 있다. 이는 점검 예시이며 확정 제공 횟수/별도 쿼터가 아니다.
3. 실제로는 입력 길이·출력·중간 단계·도구 비용으로 판단한다. 고객에게는 원가 대신 공통 작업 사용량과 남은 양을 표시한다.

[현재 원가 계산](pricing-heavy-users-2026-11-19.md)의 단독 작업 예시(예산 환율/예비비 포함):짧은 채팅약24원, 일반 문서약190원, 긴 복잡 문서약1,277원. 그러므로 다른 작업을 제외하고 짧은 채팅600회는 약14,688원, 복잡 문서12건은 약15,322원에 해당한다. 이는 내부 프로 원가 상한18,000원 **검토안**의 약80% 이상이다. 브리핑과 다른 작업을 함께 쓰면 더 적은 횟수로 한도에 도달할 수 있다. 한 번의 긴 대화/문서가 여러 모델 호출을 사용할 수 있다.

## 앞서 손익표에서 쓴 헤비 가정

아래는 실제 사용자 관측이나 가입자 평균이 아니라 **매우 강한 부하를 가정한 시나리오**다.

| 월 작업 | 라이트 보통 | 라이트 헤비 | 프로 보통 | 프로 헤비 |
|---|---:|---:|---:|---:|
| 자료 묶음 AI분류 | 220 | 2,200 | 440 | 2,200 |
| 새 브리핑 생성 | 44 | 220 | 88 | 220 |
| 직접 채팅 | 0 | 0 | 300 | 2,000 |
| 일반 문서 | 3 | 0 | 10 | 0 |
| 복잡 문서 | 0 | 10 | 0 | 40 |

프로 헤비2,000회는30일로 나누면 하루약67회 채팅이고, **복잡 문서40건·브리핑220회 등을 함께** 처리하는 가정이다. 상한이 없을 때 월 AI원가약111,078원이다. 라이트 헤비는 직접 채팅 없이도 복잡 문서10건과 대량 자료/브리핑으로 약23,814원이다.

앞선 상한 적용 손익은 이 요청을 모두 처리한다는 뜻이 아니다. 내부 원가 상한4,000/18,000원 검토안 아래 한도 초과작업을 멈춘다는 전제다. 서비스 연결 개수 제한은 자료/권한 범위를 관리하고, 월 AI 사용량 제한은 실제 작업비를 관리한다. **둘 다 필요하다.**

## 구현과 배포 상태

이번 변경은 확정한 계산 단위와 사용량 설명을 문서에 기록한 것이다. 계정 연결을 해제하거나 실사용 제한·청구·새 예산을 적용하지 않았다. 현재 실제 서버4천원/정산25% 규칙·계정권한·무료Pro와 공개사이트는 유지한다. 기존 손익 계산 수치는 변경하지 않았다.
