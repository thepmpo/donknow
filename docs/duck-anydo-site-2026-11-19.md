# 덕 소개 사이트·외부 AI 요금 개편안 — 2026-11-19

## 사용자 요청과 결과

사용자는 본인이 쓰는 GPT/Dots를 연결하는 저가 요금제와 덕 자체 AI가 작동하는 상위 요금제로 나누고, 결과는 체크 가능한 Todo로 보면서 일정으로 보내거나 대화에서 끝낼 수 있기를 원했다. 영상 없이 Any.do의 페이지 뼈대에 덕 내용만 넣는 사이트를 요청했다.

`website/`의 소개 페이지를 새로 구성했다. 큰 제목과 직접 조작하는 제품 예시 → 세 단계 사용 흐름 → Todo/캘린더 → 외부 AI/덕 AI 방식 → 연결 서비스 → 같은 문서의 요금표 → 개인정보 → FAQ → 시작 안내다. 사이트의 소개용 예시 동작이며 실제 앱 기능이나 외부 연결을 새로 만든 것은 아니다.

- 예시의 할 일로 보내기, 날짜/시간 선택 후 일정으로 보내기, 대화에서 마치기, 체크 완료/복원, 예시 초기화가 작동한다.
- 처리한 예시 항목은 브리핑에서 빠지고 해당 Todo/캘린더/기록 화면에 한 번만 나타난다. 버튼이 실제 계정에 쓰지 않는다는 안내를 유지한다.
- KR/EN(요금 정본은 한국어), 모바일 메뉴, FAQ, QR, Escape/초점 제한/초점 복귀, iPhone TestFlight 준비 안내, 동작 줄이기를 제공한다.
- 새로운 `public-site`에는 덕 PNG만 포함한다. 기존 피클 영상·배경·브랜드·수치·후기는 새 빌드에서 제외한다. 기존 참고 자산 자체와 Git 이력은 보존한다.
- 기존 origin·`/app`·`/#pricing`·`/pricing` redirect·개인정보·지원·프로젝트 문서를 유지한다. 실제 계정/원본 자료/모바일 앱/결제/AI 예산은 변경하지 않았다.

## GPT/Dots 연결에서 확인한 사실

2026-11-19 공식 문서 확인:

1. [Todoist AI](https://www.todoist.com/ko/ai-tools)와 [연결 안내](https://www.todoist.com/help/todoist/todoist-and-ai/connect-todoist-to-an-ai-assistant-xMSzFfHng): 외부 AI가 MCP/OAuth 도구를 사용해 Todoist에 읽기/쓰기를 하는 구조다. AI 자체를 외부 앱으로 복제하는 구조가 아니다.
2. [Meet dots](https://learn.chatgpt.com/docs/dots?nav=overview): Dots는 연결된 플러그인/앱의 허용된 도구를 사용할 수 있다. 덕 MCP/플러그인을 개발하고 실제 권한 아래 선택한 업무를 보내는 방향은 설계할 수 있으나 현재 구현/승인/실계정 성공은 없다.
3. [Using your ChatGPT plan in other apps and sites](https://help.openai.com/en/articles/20001542-using-your-chatgpt-plan-in-other-apps-and-sites): 지원되는 참여 상용 앱은 사용자 승인 아래 ChatGPT 사용량을 쓸 수 있다. 상용 참여/등록 조건과 사용자 요금제·한도가 적용된다. 로그인/plan usage만으로 ChatGPT 대화·기억에 접근하지 않는다. 덕의 상용 등록/지원은 확인하지 않았다.
4. 확인한 Dots 안내에서 기존 결과 전체를 자동으로 읽어오는 외부 export API를 찾지 못했다. '연결하면 Dots 전체가 자동 동기화된다'고 약속하지 않는다. 외부 AI에서 덕으로 명시 전송하는 도구와 덕 내부 비서 실행은 구분한다.

연결 모드라 해도 덕의 저장·동기화·알림·서버 비용은 남는다. 외부 AI 공급자의 사용료와 한도는 별도다. 이 작업은 실제 AI 원가/월 손익 실측이나 무손실 보장을 하지 않는다.

## 참고 자료와 접근 제한

[Any.do](https://www.any.do/)의 현재 공개 본문·목차·제품 예시·섹션 흐름을 웹 도구로 읽었다. 팀/AI agent 중심 문구는 복사하지 않고 개인 비서 덕의 자료→선택→실행 흐름으로 바꿨다. 원본의 사용자 수·후기·제휴·로고·제품 자산은 가져오지 않았다.

환경 Chromium의 Any.do 접속은 `ERR_TUNNEL_CONNECTION_FAILED`였다. 원본의 데스크톱/모바일 스크린샷·CSS 실측·모션을 확인하지 못했다. 따라서 픽셀 복제/원본 시각 일치 검수 완료를 주장하지 않는다. 사용자 요청의 페이지 구성을 참고한 덕 자체 구현으로 검수한다.
