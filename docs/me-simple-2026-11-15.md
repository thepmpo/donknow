# ME — 간결한 목록에서 상세로

사용자는 첨부한 맞춤 설정·캘린더·공급자 상세3장의 간결한 구조를 요청했다. 일반 iPhone·Duo 모두 적용하고 일반형은 웹으로만 확인하기로 답했다. 앱 안 일반형 전환은 추가하지 않는다.

ME의 첫 묶음은 **연결된 서비스 / 대화와 기억 / 동작 방식**, 두 번째는 **덕의 작업 / 브리핑·날씨 예약 / 알림**, 마지막은 **내 계정 / 데이터·개인정보 / 앱 정보·도움말**이다. 반복되는 절 제목과 긴 부제를 없애고 아이콘·이름·현재 상태·chevron만 남긴다. 동작 방식은 기존 맞춤 지침/권한 설정으로 바로 들어가며 열기만으로 설정을 변경하지 않는다.

연결된 서비스 안에는 실제 Google·Notion·Slack의 연결/준비 상태가 보이고, 다음 상세에서 기존 여러 계정·권한·가져오기·확인 후 해제를 관리한다. 오류를 연결 해제로 바꾸지 않고 재확인 필요 상태를 표시한다. 참고 화면에 있다는 이유로 비밀번호/건강/금융/Outlook/iCloud를 연결 가능으로 꾸미지 않는다. 계정 인증·로그아웃/삭제·내보내기·개인정보·고급 정보는 안쪽에서 유지한다.

기존 시스템 글꼴·의미 색과 Ionicons를 사용하고60pt 이상 행·44pt 터치·긴 이름 줄바꿈·오른쪽 상태 공간을 유지한다. 경계선은 글자 시작에 맞춰 들여 쓴다. 일반형은 하단5탭, Duo는 카메라 열과 반대 화면을 그대로 쓴다. 다른 시트의 입력/키보드·배경 dim·3초 Todo 이동을 바꾸지 않는다.

일반형 확인은 iPhone/Duo의 Safari에서 [웹 앱](https://duckduck-test.onrender.com)을 열어 **ME**를 선택한다. 같은 계정이면 서버에 저장된 자료를 사용하고, native 키보드 도구 모음·알림·OS 권한은 설치 앱에서 확인해야 한다. 웹 확인을 다른 하드웨어에서의 native 검수라고 표현하지 않는다.
