# 덕 요금제·문서 작성·헤비 유저 손익 검토

기준: 2026년 11월 19일, 한국 시간. **사업 검토용 가정 계산이며 실제 매출·청구서·순이익이 아니다.** 금액은 원/월, 소비자 가격은 부가세 포함이다.

## 먼저 결론

**라이트 16,900원 / 프로 49,900원 / 비즈니스 상담형을 추천한다. 단, 두 유료 요금제의 AI 사용량을 서버에서 제한해야 한다.** 라이트는 브리핑·자료 정리·지원 문서 초안·Todo/일정 전환을 프로와 공유하고, 직접 AI 채팅은 프로에 포함하는 해석이다. 사용자에게 차이를 확인하는 질문을 보냈으며 답변에 따라 이 항목만 조정한다.

유료100명, 라이트60%·프로40%, 헤비50% 시 상한이 없으면 운영잔액은 **-1,407,591원**, 제안 상한을 실제로 집행하면 **1,048,377원**다. 인건비300만 원을 빼면 **-1,951,623원**다. 가격을 올렸다는 이유만으로 초기 적자가 사라지지는 않는다.

제안 상한 아래 같은 가입자 구성에서 헤비100%여도 인건비 전 운영손익분기점은 유료 **25명**, 인건비300만 원 포함은 **313명**이다. 이는 인프라/운영 고정 예산 월25만 원이 유지되는 계산 경계이며, 실제 부하·CS·환불·보안 비용이 더 들면 올라간다.

‘같은 기능’은 라이트와 프로가 **같은 핵심 정리 흐름과 문서 초안 기능**을 공유한다는 뜻으로 표시했다. 고객이 직접 질문하고 자유롭게 대화하는 진입은 프로 전용 해석이다. 라이트에도 직접 채팅을 넣고 사용량만 차등화하려는 의도라면 기능표의 채팅 행과 비용 시나리오를 조정해야 한다.

웹 소개는 PC/모바일에 같은 시각 체계를 유지했다. PC 네이티브 앱이나 기존 실제 웹앱 화면을 새로 만든 것은 아니다. 비즈니스 상담 CTA는 기존 지원 페이지로 연결하며, 실제 팀 공유/SSO/감사 로그 같은 미구현 기능을 현재 제공으로 약속하지 않는다. 외부 GPT/Dots 연결 준비 상태는 별도로 유지한다.

원가 원화는 **내부 운영 기준**이며 고객 요금표에는 노출하지 않는다. 월 메시지 수만 제한하면 긴 문서/긴 대화가 원가를 초과할 수 있다. 고객에게는 공통 작업 사용량·문서 크기/작업별 차감·월 잔여량을 보여주고, 비용 추정과 실제 토큰/도구 사용량으로 서버에서 집행한다. 브리핑·새 요청·실패·문서 수정·재작성을 같은 예산에 넣고 동시 실행 전 원자적으로 선예약해야 한다. 자료 조회/권한 실패를 무제한 재시도하지 않는다.

현재 서버는 절대4,000원·확인 정산액의25% 상한을 가진다. **프로18,000원은 아직 실제 서버에 적용하지 않았다.** 신규 플랜별 정책·정산 검증·할당·공급자 한도·도구별 과금을 정리하고 테스트한 뒤에만 올린다. 이 사이트 수정으로 실제 계정 권한·AI 잔액·키·유료 자원·결제는 바꾸지 않았다.

예시 입력/응답 길이와 정상 브리핑·문서10건을 가정하면 프로18,000원 안에서 직접 채팅은 월 약 **517회**에 해당한다. 이는 **보장 제공 횟수가 아니다.** 더 긴 대화/문서/유료 도구를 쓰면 줄어든다. 매번220개 브리핑을 전부 새로 생성하는 사용자는 대화 여유가 더 작아진다. 변경이 없으면 생성하지 않는 구조와 실제 계측이 필요하다.

## 3. 문서 작성까지 넣은 원가

공식 API 표준 요금: GPT-5.4 mini 입력$0.75/출력$4.50, nano 입력$0.20/출력$1.25, 각각100만 토큰당이다. 계산용 환율1달러1,600원에 AI 비용20% 예비비를 더했다. 캐시·Batch 할인은 적용하지 않았다. 출력 가정에는 중간 처리와 reasoning을 포함하며 문서 생성은 여러 번의 모델 호출을 합산했다.

| 작업 | 합산 입력/출력 가정 | 월별 원가가 아닌 1회 예상 원가 |
|---|---|---|
| 자료 묶음 분류(nano) | 4,000 / 300 토큰 | 2원 |
| 브리핑1회(mini) | 12,000 / 1,200 토큰 | 28원 |
| 직접 채팅1턴(mini) | 8,000 / 1,500 토큰 | 24원 |
| 일반 문서1건 | 3단계 합계60,000 / 12,000 토큰 | 190원 |
| 복잡한 문서1건 | 5단계 합계600,000 / 30,000 + 검색5회 +1GB컨테이너1세션 | 1,277원 |

문서는 초안→수정→검토에서 원가가 늘어난다. 텍스트 초안과 로컬 파일 렌더링을 기본으로 보고, 유료 웹 검색·OCR·이미지 생성·대용량 분석/컴퓨터는 별도 가중 사용량·최대 입력·실행 시간으로 관리한다. 모든 PDF/이미지/파일을 무제한 처리한다는 약속은 없다. 파일 형식·한글·레이아웃·산출물 재읽기와 실제 자료 근거를 검증해야 한다.

공식 유료 도구 요금 가정: 웹 검색$10/1,000회에 검색 본문 토큰 별도, 컨테이너1GB$0.03/20분 세션. 도구가 모델 호출을 대신하는 것은 아니므로 두 비용을 합산했다. 이 도구들이 실제 덕 계정에서 활성화되었다는 의미는 아니다. 현재 비용 검증이 안 된 유료 도구는 코드에서 차단된다.

## 8. 서버비·수수료·비용 범위

- VAT10%: 표시 가격을1.1로 나눠 공급가액을 계산한다.
- 웹 결제비: 표시 결제액의3.85%를 보수적인 비용 가정으로 차감했다. **계약된 PG 견적이나 실제 정산율이 아니다.** PSP의 부가세·최소 수수료·카드/해외 결제·환불 조건에 따라 다시 계산한다.
- 환불 예비비: 소비자 결제액의2%. 실제 환불/차지백이 늘면 부족할 수 있다.
- 고객 대응: 보통1,000원/헤비3,000원, 유지 마케팅1,500원/유료1명(예:CAC3만원×이탈5%), 유료 자료 저장/색인 예비비200원/명.
- 무료 계정: 유료1명당 무료3명, 월300원/무료1명. 무료 AI 생성은 제외한다.
- 공통 인프라 월20만 원: 상시 앱/작업 처리9만·DB/파일/백업6만·메일/로그/모니터링3만·도메인/개발자 계정 등2만의 **계획 예산**이다. 공급자 청구서·성능 검증을 대신하지 않는다. 현재 무료 Render를 유료로 바꾸거나 새 자원을 만들지 않았다.
- 운영/보안/회계 등 예비비 월5만 원. 실제 Google 제한 범위 심사·법무·보안 평가·추가 채용 견적이 크면 별도 비용이다. 5만 원으로 모두 해결된다는 뜻은 아니다.
- 인건비 월300만 원을 별도 열에서 차감했다. 법인세/소득세·추가 성장 광고·초기 개발비 회수·여러 명의 급여·미확정 외부 심사 비용은 포함하지 않았다. 따라서 표의 운영 잔액을 최종 순이익이라고 부르지 않는다.
- 외부 AI 사용자 구독 비용은 덕의 직접 원가로 넣지 않았다. 외부 연동 요금과 내부 AI 처리를 자동으로 이중 제공하지 않는다. ChatGPT 구독 공유/상용 등록 및 Dots 결과 가져오기는 별도 조건이다.

환율/모델 단가가 올라가도 비용 상한을 실제 원화 예산으로 집행하면 제공 가능한 작업량이 줄어들 수 있다. 고객에게 이를 숨기고 동일 횟수 무제한을 약속하면 안 된다. 매출 정산 전 무료 체험·테스트 Pro 권한은 결제 입금이 아니며, 자동 충전·자동 초과 결제는 하지 않는다.

## 9. 비즈니스 견적 기준

팀/자료량/문서 복잡도/작업 주기/연결 방식/사람이 대응하는 시간을 먼저 확인한다. 팀 사용량 공유 여부와 사용자별 상한도 계약에 넣는다. 모든 경우에 SSO·전담 운영·보안 심사를 기본 포함한다고 약속하지 않는다.

예상 직접비용 C, 목표 기여이익률 m, PG/환불 가정 f/r이면 부가세 포함 견적의 최소 검토식은 `C / (1-m) / (1/1.1-f-r)`이다. 실제 인프라 배분·도입비·계약 요구사항도 C에 넣고 현지 정산/세금을 다시 확인한다. 비즈니스 매출이 개인 플랜 적자를 자동 보전한다는 가정은 이번 계산에 없다.

## 10. 구현/출시 전에 남은 일

1. 라이트 직접 채팅 포함 여부를 사용자 답변과 맞추고 고객용 한도/차감 표를 확정한다.
2. 정기 브리핑·변경 없음 차단·자료 묶음 처리·토큰/도구/문서 수정 로그를 계측한다.
3. 실제 모델/품질을 검증하고 플랜별 예산 선예약·동시성·실패/불확실 응답 처리·파일/시간/사용량 제한을 검사한다.
4. 현재 서버4천원 상한과25% 정산 규칙을 새 정책에 맞춰 검토하되, 실제 입금/동의 없이 예산을 만들지 않는다.
5. 웹 결제 계약·모바일 이용 경로/정책·환불/영수증·원가/부하를 확인한 뒤 결제를 연다. 이번 작업은 새 결제나 유료 자원을 활성화하지 않았다.
