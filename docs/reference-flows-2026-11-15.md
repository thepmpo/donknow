# Things·피클 영상 기준 UX/UI 구현

사용자 요청: 여러 번 나눠 보낸 Things와 피클 영상을 오류 제보가 아닌 디자인·조작 참고로 검토하고, 제품 디자이너 관점에서 덕에 적용한다. 일반 iPhone은 기존 하단 탭, Duo 접힘·펼침은 카메라 열과 반대쪽 캘린더를 유지한다.

## 확인한 참고와 적용 범위

총5개 첨부 중 `00-11-48` 두 MOV는 SHA-256이 같아 실제4개다. 원본·개인 계정 화면은 공개 이미지에 포함하지 않는다. 촬영 화면 검토이며 타 앱의 내부 구현이나 접근성·보안 인증을 검증한 것이 아니다.

| 영상 | 실제 확인 | 덕에 적용 |
| --- | --- | --- |
| 23-53-47 /16.88초 | 입력창·키보드, 응답 대기, 출처 링크 | 첨부는 입력창의＋, 전송은 라이브러리 아이콘, 출처는 작은 묶음. 시각·대기·명시 재시도와 실패 입력 보존 유지 |
| 23-54-23 /34.80초 | ME 묶음 목록, 상세 이동, 알림, 디자인 미리보기, 사용량·초기화 티켓 | 기존 ME의 목록 구조를 유지하고 서비스 권한·가져오기·문제 해결을 별도 페이지로 통일 |
| 23-58-55 /10.19초 | 날짜→일정→체크 목록, 목록 안 편집, 다중 선택·작업 막대 |44pt 기본 행, 원래 위치의 편집, 날짜별 추가, 다중 선택 후 날짜 변경·완료 |
| 00-11-48 /23.21초 | 연결 목록→서비스 소개→미리 알림 설명→OS 권한→설정 안내 | 미리 알림 소개·권한 설명→목록→항목 선택을 분리하고 권한 오류의 설정 복구 진입 제공 |

실제 구독 가격표·등급별 제한은 영상에 없다. 가격·사용량 숫자·티켓을 임의로 만들거나 결제를 붙이지 않았다. Things의 태그/깃발 등 덕의 저장 모델이 지원하지 않는 조작도 가짜 버튼으로 추가하지 않았다. 피클의 전화와 첫 채팅의 비서/오늘 내용 등의 숨김 요청은 유지한다.

## 투두 동작

- 기본 행은44pt, 제목은 두 줄까지 허용하고 상태·카운트다운·큰 글자에 따라 높아진다. 체크 시 기존3초→350ms→log와 복원을 유지한다.
- 제목·새 할 일을 누르면 해당 목록 위치에 하나의 편집기를 연다. 제목·메모를 먼저 보여주고 날짜·알림·공유/삭제는 작은 도구로 연다. 저장/취소는 명시적이다. 키보드 또는 날짜 선택 중 저장은 숨긴다.
- 기존 TodoEditorForm의 검증·저장·삭제·공유·원본 재시도를 그대로 사용한다. 캘린더에서 여는 편집은 기존 시트를 유지한다.
- 목록의 기존 ScrollArea가 입력란/선택기를 드러낸다. 본문·반대 pane 전체를 띄우거나 입력란을 복제하지 않는다. compact 메모는72~160pt와 내부 스크롤로 긴 입력의 커서를 유지한다. 다른 화면의 기본 메모220pt 규칙은 바꾸지 않는다.
- 저장 도중 날짜가 낙관적으로 바뀌어도 열린 편집의 원래 그룹을 유지해 폼이 사라지지 않게 한다. 실패하면 입력을 보존하고 사용자가 재시도한다.
- 투두 탭을 숨겼다가 다시 보여주므로 다른 탭을 다녀와도 초안/선택은 유지된다. 숨긴 투두는 캘린더 조회와 Duo 뒤로가기 등록을 중단한다. 계정·서버 변경/로그아웃에서는 초기화한다. 앱 완전 종료 후 초안 복원을 보장하는 기능은 아니다.
- 선택과 완료는 구분한다. 선택만으로는 쓰지 않는다. ‘날짜 변경→저장’ 또는 ‘완료하기’에서 각 항목의 기존 store.update를 순서대로 호출한다. 성공한 요청은 재실행하지 않으며 실패한 ID만 선택에 남긴다. 날짜 선택은 목록 안에서 스크롤하고 작은 작업 막대는 일반폰 하단 탭 위에 둔다.

## ME와 연결

- ME→연결된 서비스→공급자 소개/실제 상태→계정·권한·자료·완료 동기화·문제 해결로 이동한다. 뒤로가기는 한 단계씩 복귀한다. 설정을 시트 여러 겹으로 쌓지 않는다.
- 미연결 서비스는 기능/변경 경계를 설명한 뒤 ‘연결할 자료 선택’으로 권한 페이지를 연다. 준비되지 않은 공급자는 설명은 읽을 수 있지만 연결 CTA는 비활성화한다.
- 권한 선택만으로 실제 승인됨으로 표시하지 않는다. 별도 OAuth 승인·Google 계정 격리·완료 동기화 opt-in·해제 확인·가져온 자료 보존·마지막 연결 상태 보존을 유지한다.
- Apple 미리 알림은 소개→기기 권한 확인→목록→선택 항목 가져오기다. 완료 기록과 완료 상태 맞추기는 별도다. 웹에서는 설명과 아이폰 필요 상태만 보여주고 기기 연결로 가장하지 않는다.
- 빈 목록에 ‘선택한0개 가져오기’를 먼저 내놓지 않는다. 실제 항목이 있을 때 선택·가져오기를 보여준다. 거절·접근 오류에는 아이폰 설정 열기와 다시 읽기를 제공한다.

## 채팅과 유지 조건

‘나’ 표시는 말풍선마다 반복하지 않고, 메시지 시각은 유지한다. 첨부 버튼은 입력창에 위치하고 출처는 실제 응답의 링크만 묶는다. AI 실패를 Todo로 바꾸지 않으며 요청 자동 재전송을 추가하지 않는다. 기존 긴 답변·스크롤 의도·동의·원본 실행 확인·실패 입력 복구를 보존한다.

캘린더 캐시·원본 쓰기/ETag·계정 경계·기억/브리핑 설정·API 키/DB/서명·원본 복구 bundle은 변경하지 않았다. 기존 Slack을 재연결하지 않았다. 운영 AI의 이전 `credit_balance_exhausted`는 이 UI 작업으로 해결됐다고 보고하지 않는다.
