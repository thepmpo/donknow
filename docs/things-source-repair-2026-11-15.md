# Things형 할 일·원본 저장·연결 오류 수정

사용자의 마지막 Things 3 Upcoming 사진을 목록 구조 기준으로 적용한다. 일반 iPhone과 Duo 접힘·펼침에 같은 Todo를 쓰고 기존 하단 탭·카메라 열·반대 pane을 유지한다. [검사와 9장](things-source-repair-qa-2026-11-15.md), [확인된 AI 연결 원인](ai-connection-investigation-2026-11-15.md)을 함께 읽는다.

## 할 일 화면

큰 날짜 숫자와 요일·가로선으로 날짜를 구분하고, 그날의 캘린더 일정 아래에 ‘새 할 일’과 체크 목록을 둔다. 반복되는 항목별 날짜·출처·점 메뉴는 줄이고 본문을 누르면 편집한다. 날짜 없는 일과 지난 일은 별도 묶음이다. 오늘 일이 없으면 다음 할 일이 있는 날짜부터 보이며, 완전히 빈 목록은 오늘 추가 진입을 남긴다. 일정은 선택한 캘린더의 앞으로 14일을 함께 보여주고 미래 Todo는 그 이후도 표시한다. 원본 페이지가 더 있으면 더 불러오기를 제공한다.

간결한 목록을 위해 체크 행은 약48pt이며 긴 제목·오류·카운트다운은 늘어난 높이를 사용한다. 체크/좌우 스와이프와3초 되돌리기·log 복원은 유지한다. Things의 브랜드·영문·사용자 데이터·단독 +·시스템 상태 열을 복제하지 않는다. 덕의 의미 색·한글·기존 내비게이션 안에 구조를 적용한다.

## 원본 내용·예정일·시간 저장

사용자가 편집 후 저장한 필드만 원본에 적용한다. Google Calendar는 같은 계정·달력·이벤트를 조회하고 수정 권한과 ETag/If-Match를 확인한다. 제목·메모만 바꾸면 시간·참석자·반복 설정을 재작성하지 않는다. 날짜/시간을 바꾸면 조회한 길이와 표시 시간대를 사용한다. Google Tasks는 제목·메모·예정일을 지원하며 예정 시간은 원본 API가 지원하지 않는다.

아이폰 미리 알림은 해당 항목을 읽을 수 있는 iPhone에서 REMINDER 권한과 원본 마지막 변경 시간을 확인하고 `ExpoCalendarReminder.update`로 선택 필드만 수정한다. 날짜 해제는 시간도 해제하며 기존 시작일보다 앞당길 때 잘못된 시작일을 남기지 않는다. 완료·반복·알람은 이 내용 편집에서 덮지 않는다. 완료 상태 맞추기와 기존 Google 완료 동기화 선택은 별도로 유지한다.

덕 저장과 원본 저장 결과를 구분한다. 원본 저장 전 불확실 상태/개정/필드를 먼저 보관하므로 서버 종료로 성공 표시를 추정하지 않는다. 실패/불확실/기기 필요에는 목록 상태와 편집 내 재시도를 제공한다. 모델 없이도 소유자의 덕 채팅에 이유와 원본 앱·권한 확인·다른 기기·덕 알림 같은 대안을 보낸다. 같은 항목의 동시 편집을 막고 불확실 쓰기를 자동 재실행하지 않는다. 지원하지 않는 공급자 자료는 원본 앱에서 수정해야 한다고 명시한다. AI에서 명시 확인한 Todo 수정도 같은 쓰기 경로와 원래의 미리보기 버전 검사를 사용한다.

Google 원본 반영이 확인되면 해당 계정의 캘린더 표시 저장본에 변경 필드만 즉시 반영하고 다시 조회한다. 실패·다른 이벤트·다른 계정은 표시 저장본을 바꾸지 않는다. 다른 기간·시간대의 저장본, 늦은 응답, 로그아웃/해제 격리는 유지한다.

## 미리 알림 가져오기

이전 CALENDARWRITEONLY 오류와 사용자가 새로 보낸 ‘목록은 보이지만 항목은 비어 있음’을 구분한다. 이미 허용한 권한을 다시 요청하지 않고 선택 목록을 REMINDER 범위로 새로 조회한다. 날짜 없는 항목을 포함해 전체 상태를 읽고 공유 객체의 값을 즉시 일반 데이터로 복사한 뒤 완료 여부를 구분한다. 빈 응답은250ms 뒤 새 목록 객체로 한 번만 더 확인한다. 무한 재시도나 이벤트 캘린더 쓰기 권한 요청은 하지 않는다.

목록 이름 옆 선택 상태·조회 중 표시·다시 읽기를 제공한다. ‘모두 완료됨’, ‘목록이 없음/권한 실패’, ‘빈 응답’을 나눈다. 빈 경우 원본 앱/iCloud·계정 동기화/설정 확인 대안을 채팅에도 남긴다. 최대20개씩 제목·메모·예정 시간·수정 시각을 가져오며20개의 한국어4,000자 메모도 요청 크기 안에 들어간다. 완료 기록은 참고만 한다. 실기기 iCloud 조회 성공은 자동 테스트로 대신 확정하지 않는다.

## 기본 설정과 화면 정리

처음 설정하는 인증 계정은 브리핑을 평일9–18시 매시 정각, 중요 변화 알림, 연결된 읽기 자료, 알림을 켠 상태로 시작한다. 표시만 켜는 것이 아니라 실제 예약과 비서 설정을 초기화한다. 명시적으로 저장한 끄기·원본 자료 선택·복원 후 중지는 덮지 않는다. 실제 iOS 알림 허용과 OAuth 권한은 여전히 필요하며 허용된 것처럼 가장하지 않는다. Google 새 연결의 읽기 자료와 Calendar/Tasks 수정 선택을 기본 체크하되 계정의 실제 OAuth 동의가 필요하다.

전화 진입만 숨기고 파일 첨부는 유지한다. 월 그리드의 첫 주 선은 해당 월1일 칸부터 시작한다. 이전 달 칸 위에는 선을 두지 않는다. 기존 AI 첫 화면 보조 진입 숨김·X 위 별도 키보드 버튼·고정 편집창 내부 스크롤을 유지한다.

## 실행 상태와 남은 확인
