# 날짜별·출처별 Todo와 비용 제한 — 2026-11-16

## 사용자 확정과 구현

Pro 소비자가격은 월27,900원이며 Light는 제거한다. 선택한 결합안은 상단 날짜별/출처별 전환, 날짜별은 큰 날짜/요일/선 아래 일정과 Todo, 출처별은 Slack/Google Tasks/미리알림 등의 묶음이다. 각 Todo에 날짜·실제 출처를 표시하고 확인 가능한 원본 링크를 제공한다. Apple 미리알림의 확인되지 않은 deep link를 만들지 않는다. 원본 링크는 소유자 검사와 공급자 HTTPS 호스트 제한을 거친다.

길게 눌러 한 개 또는 선택한 여러 개를 이동한다. 날짜별 드롭은 예정일 저장과 기존 원본 전파/실패 복구 경로를 사용한다. 출처별은 같은 공급자 그룹 안에서 순서만 바꾼다. 위/아래 이동 버튼도 제공한다. 순서는 계정별 DB에 저장하며 원본 출처·완료 상태를 바꾸지 않는다. 부분 실패는 남은 항목만 선택하고 성공한 원본 저장을 다시 실행하지 않는다. 긴 문구/메모/inline 편집·3초 완료/log·키보드 내부 스크롤·일반5탭·Duo 카메라 열/반대 pane을 유지한다.

## 비용 제한의 실제 범위

무료는 연결된 자료의 제목·날짜/원본 참조와 기본 일정·할 일을 받는다. 직접 채팅 입력은 숨긴다. 이 기본 브리핑은 LLM 의미 분석이 아니며 읽은 범위/본문 미분석을 명시한다. 새 수신 항목을 Todo로 전환하는 동작은 서버에서 유료 할당 유무를 검사한다. 기존 Todo는 예산 소진 후에도 사용한다. **수신 항목을 캘린더로 직접 전환하는 별도 버튼과 자동 구독 결제는 아직 구현하지 않았다.** 기존 일정 작성/확인 API를 이것의 완료로 보고하지 않는다.

정산을 확인한 돈 중 최대25%, 사용자당 UTC 월 최대4,000원만 AI 원가 예산으로 할당할 수 있다. 기본 할당은0원이고 자동 갱신·자동 추가 결제는 없다. 과금 요청 전 보수적인 상한을 DB 트랜잭션으로 예약하고 확인된 실제 토큰만 정산한다. 동시 실행은 같은 잔액을 중복 사용하지 못한다. 네트워크 오류/usage 누락은 예약액을 유지한다. 알 수 없는 모델/무제한 응답/hosted 검색·코드·PDF/이미지·음성은 비용 확인 전 차단한다. 연결 문서의 텍스트 읽기/검색은 기존 범위를 유지한다. 함수 호출의 후속 모델 요청과 임베딩도 같은 원장을 거친다.

변경 없는5분 폴링은 모델 작업을 만들지 않는다. 최초 조회는 baseline을 저장하며 경고/부분 실패는 성공으로 덮지 않는다. 매시간 브리핑도 자료가 같으면 모델을 다시 부르지 않는다. 시간 변경과 소스 삭제는 변화로 처리한다. 외부 변경 이벤트의 parent/control 알림은 child와 중복 분석하지 않는다.

운영 도구: `scripts/fund-ai-budget.mjs --verified-settlement --email <계정> --reference <고유정산참조> --net-krw <실제정산금액>`. 이 플래그는 **운영자의 정산 확인 선언**이며 Apple 영수증을 검증하는 구현이 아니다. 실제 정산 증거가 없으면 실행하지 않는다. 이번 작업에서 운영 계정에 예산을 부여하거나 API 결제를 충전하지 않았다. 이전 실제 `credit_balance_exhausted` 오류도 해결됐다고 보고하지 않는다. 외부 AI API 자체의 한도/가격/환율 변경은 별도 모니터링 대상이다.

## 손실에 대한 설명

아무 조건 없는 무손실 보장은 불가능하다. 무고객·환불·기존 연간 회원비·인건비·보안/법무·성장 광고비가 있으면 적자가 발생할 수 있다. 코드가 보장하는 것은 할당 없는 유료 AI 요청 차단과 사용자별 원가 예산 검사다. StoreKit 결제/구독 검증·환불 회수·자동 정산 연동은 아직 없으며 이를 유료 상품 출시 완료로 표시하지 않는다.

기존 Render free/Turso 설정을 유지하고 유료 서버/유료 runner/자동 과금을 새로 만들지 않는다. 무료 서버의 sleep/cold start와 조회 지연 때문에 상시 실시간 SLA를 보장하지 않는다. 유료 인프라 전환은 실수령 매출로 원가를 감당하는지 확인한 뒤 별도로 결정한다.
