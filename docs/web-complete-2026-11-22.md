# 실제 덕 웹앱 기능 연결 — 2026-11-22

사용자는 PC 웹앱을 시안에서 끝내지 말고 전체 메뉴와 기능 연결까지 완성하라고 요청했다. 대상은 기존 /app이다. 소개 페이지/새 native 앱 작업으로 바꾸지 않는다. 소개와 요금은 기존 /, /#pricing에 유지한다.

## 구현과 연결

- 상단 대화 버튼은 어디에서든 기존 덕 채팅을 열고 작성 중인 입력을 유지한다. 왼쪽 서비스 연결/브리핑 예약은 ME 내부의 실제 페이지를 직접 연다. ME 재선택은 웹에서 설정의 첫 화면으로 돌아온다.
- 브리핑은 받은 메시지 최근5개와 이전 내용 더 보기를 제공한다. 새로고침은 상태와 메시지를 다시 읽으며, 연결 실패를 빈 브리핑 성공처럼 표시하지 않는다. 실패 시 기존 수신 내용을 보존한다. 체크·Todo·캘린더·원본 링크는 기존 서버의 확인/저장 경로다.
- 캘린더 전환은 날짜/시간·저장 대상 선택→미리보기→명시 확인이다. 확인 전 쓰지 않고 응답이 불명확하면 덕의 저장 결과 확인으로 기존 실행을 읽는다. 자동 재전송하지 않는다. 저장 결과 확인 버튼을 웹 브리핑에도 연결했다.
- Google/Slack/Notion의 인증 팝업은 클릭 순간 열고 허용한 HTTPS 호스트만 사용한다. 부모창 접근은 끊는다. 팝업 닫힘/웹 복귀 시 서버 상태를 다시 읽고 페이지 이탈/10분 후 감시를 정리한다. 브라우저 분리 정책으로 닫힘이 일찍 관찰돼도 실제 복귀 시 다시 확인할 수 있다. 기존 계정/권한/원본 쓰기 확인은 유지한다.
- Todo 작성·수정·완료·기록·복원·저장은 실제 기존 repository와 서버를 사용한다. 메모 저장은 서버 기능 지원을 쓰기 전에 확인해 미지원 시 초안 입력을 보존하며, 확인한 쓰기는 기존 낙관적 저장 경로를 유지한다. 계정 전환 중 검사가 끝난 결과는 새 계정에 저장하지 않는다.
- 맞춤 지침/기억/브리핑 예약/자료 연결/첨부·다운로드/JSON 내보내기/계정 관리는 기존 API와 연결한다. 작은 화면5탭과 Duo 기하는 웹 공유 코드 호환 검사이며 이번 요청의 제품 대상은 PC 웹이다. 막힌 배경 메뉴는 비활성화하고 dim한다.

## 실제 사용자 계정·운영

연결 UI와 API 경로가 동작하는 것과 사용자의 외부 계정 승인은 다르다. 실제 웹에서 로그인/이메일 인증 후 Google·Slack·Notion 권한을 사용자가 승인해야 한다. 공급자 앱 등록이 없는 연결은 준비 상태를 표시하며 임의로 키를 만들거나 ChatGPT의 연결을 가져오지 않는다. 아이폰 미리알림의 기기 권한/가져오기는 웹에서 실행할 수 없으며 앱을 안내한다.

실제 모델 생성에는 기존 서버의 AI 설정·자료 동의·사용 권한·입금된 예산이 필요하다. 이번 작업에서 키/자금/실제 예산/정산/요금제 권한을 우회하거나 자동 반복 전송을 켜지 않았다. 실제 모델 품질·운영 계정 OAuth·원본 쓰기는 합성 검수로 대신하지 않는다. 현재 웹에 표시된 정상 월19,900/55,900·베타 월16,900/49,900·연간202,800/598,800원과 무료 서버 정책을 유지한다.

최종 공개 배포는 별도 Render live 영수증과 /api/health의 release로 확인한다. 검증된 코드·GitHub 저장과 운영 서버 반영을 구분한다.
