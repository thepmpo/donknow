# 웹사이트 상단 포맷으로 실제 웹앱 수정

사용자 정정: 앱을 그대로 웹에 넣는 것이 아니라 소개 사이트 상단의 나의 하루 예시를 실제 /app의 형식으로 사용한다.

## 시각 기준과 수정

정본은 `website/src/App.jsx`의 Demo와 `website/src/styles.css`다. 상단 54px, 최대1128px 프레임,171px 왼쪽 메뉴,245px 오늘 영역,중앙30px 여백과25px 제목이다. 브리핑의 큰 메시지 제목·그룹 안내가 항목을 밀어내던 부분을 없애고 체크·작은 제목·출처 링크/날짜·설명·할 일로/일정으로/대화에서 마치기를 같은 행 체계로 구현했다. 원문은 전체 내용 보기로 열며 숨겨서 잃어버리지 않는다. 출처 중복 표시는 제거했다.

웹은 모든 너비에서 이 작업공간을 사용한다.1100px 미만 오늘 영역을 접고760px 미만 메뉴가 상단 가로가 된다. 실제 네이티브 iPhone과 Duo 경로는 유지한다. Todo·ME·공통 제목/본문 여백/행은 웹 전용 context 안에서만 작은 밀도를 적용한다. 요금표와 서버·권한·원본 쓰기/예산은 변경하지 않았다.
