필수 로그인 쿠키

웹의 duckduck_session은 일반 회원 로그인 유지에 사용하는 필수 쿠키이며 기본 만료는 30일입니다. 관리자는 별도 duckduck_admin_session을 쓰며 기본 8시간, 초기 비밀번호 변경 세션은 10분입니다. 쿠키는 HttpOnly·SameSite Strict, 운영 HTTPS에서 Secure 설정을 사용합니다. 로그인/보안 기능을 위해 사용하며 광고 추적용이 아닙니다. 쿠키를 차단하면 웹 로그인 유지가 되지 않을 수 있습니다.

앱과 브라우저의 기기 보관

아이폰 로그인 토큰은 기기의 보안 저장소에 보관합니다. 체험 자료·서버 주소·표시 설정·일부 캘린더/할 일 캐시는 기기에 남을 수 있습니다. 최근 화면을 먼저 보여주고 갱신하기 위해 사용하며 계정 전환과 로그아웃 시 계정 자료를 구분해 정리합니다. 웹에서 로그인 비밀번호를 localStorage에 저장하지 않습니다.

관리 방법

로그아웃하면 해당 서버 세션을 폐기합니다. 브라우저의 사이트 데이터 삭제, 앱 내 연결·로그아웃·자료 삭제 기능을 이용할 수 있습니다. 브라우저 데이터 삭제만으로 서버의 회원 계정이 탈퇴되는 것은 아닙니다. 광고·선택 분석 쿠키를 도입한다면 종류·목적·보관 기간·거부 방법을 알리고 필요한 별도 동의를 제공하겠습니다. 현재 가입에는 마케팅·광고 추적 동의가 없습니다.
