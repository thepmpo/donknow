최신 캘린더 · 일반폰/Duo 단축 · 년월 UI는 미정

구현 계약 · 검수 · Apple 영상/년월 선택 비교.

일반 iPhone은 다른 탭에서 들어갈 때도, 현재 캘린더 탭을 다시 누를 때도 오늘로 이동한다. 길게 누르면2주 보기이며 상단의 보기 버튼은 유지한다. Duo는 오늘 →2주 보기→5탭 배치를 유지하고, 캘린더 재선택은 오늘·길게 누르기는2주다. 펼친 가로에서 오른쪽이 캘린더면 오른쪽에 적용, 다른 탭이면 왼쪽 고정 캘린더에 적용하고 오른쪽 작업을 보존한다. 첫 캘린더 진입 때 보던 날짜를 유지하는 Duo 규칙은 일반폰과 다르다.

길게 누르기500ms·2주로 직접 설정·손뗄때중복Today 차단, 계정/서버·pane별 요청 격리·열린 시트 단축 무시를 구현했다. 앱복귀/접힘/회전 자체를 탭선택으로 취급하지 않는다. 기존 Glass/캐시/원본쓰기 확인·인증/데이터는 보존한다. 년월 UI/Apple 연간 줌은 별도 질문 답변 대기이며 변경하지 않았다. 아래 과거의 모든질문대기/앱변경없음 설명은 이번 두 답변 이전 이력이다. 단축은 덕의 선택이고 Apple이 규정한 탭동작이 아니다. '포스터치'는 이번에는 압력 감지 대신 길게 누르기(Haptic Touch)로 구현한다.

Expo 웹/합성API·명시적 Duo기하 검사는 통과했다. native iPhone의 길게누르기/진동/VoiceOver·실계정은 별도다. 이번 조작은 기존1.0.0(27)에 없으며 새native빌드가 필요하다. 이번에는 native빌드를 시작하지 않았다.

가장 최신 캘린더 · 화면 채우기·버튼 순서·일정 먼저 표시

현재 구현 계약과 시각/기능 QA가 이전24pt 여백/92pt 최소 주 높이/월 내부 스크롤/Today 위 보기 버튼을 대체한다. 월과2주 행은 실제 가용 높이를 정확히 나눠 채우며 세로 스크롤·bounce·스크롤바가 없다. 요일 줄은 Todo 날짜 줄과 같은 본문 시작선, 공통 제목은 기존16/26/35/16·inset24를 유지한다. 긴 시트/목록/시간표는 스크롤을 유지하고 숫자·일정 정보량은 높이에 맞춘다.

사용자 확정으로 Duo 카메라 열의 Today가 위,2주 보기 버튼이 아래다.64pt 원형·8pt 간격/기존5탭/Back·pane/회전·접힘 상태를 보존한다. 일반폰의2주 보기는 제목 옆 겹친 달력 아이콘,Today는 년·월 메뉴 안이다. 일반폰 화면과 Today 메뉴를 확인한다.

이미 읽은 일정은 먼저 보여주고 갱신한다. 계정/서버/시간대별12기간 실행 메모리 캐시,출처별 점진 반영·기능확인5분 캐시·페이지 완료 후 삭제·늦은 계정응답 폐기·일시 실패 보존을 사용한다. 첫 조회·앱 완전 재시작은 실제 네트워크가 필요하다. 실계정/native를 웹 fixture로 통과 처리하지 않는다.

최신 캘린더 · 정리·2주·시트·연동

현재 구현/수치 계약과 실제 QA가 이전42칸/본문 도구 규칙보다 우선한다. 도구/조회 문구는 년월 sheet로 이동·여백24pt, 월에 실제 속한 주만4/5/6줄(11월은12월5일까지), 일요일 빨강·토요일 파랑·옆 달 연한 숫자다.2주 모드는14일 두 줄을 실측 높이로 넓히고 선택일/anchor를 분리해 날짜 선택 때 창을 보존한다.

Duo Today 위64pt 보기 버튼·8pt 간격, 기존 카메라 열/5탭/가로 고정왼쪽·오른쪽 선택/상태 보존. 일반폰은 헤더 보기 버튼과 기존 하단 탭이다. 시트 입장360ms/퇴장260ms·dim220ms,같은 회색이 해당 pane 상단까지 이어지고 회색 본문/상단 탭으로 닫는다. 다른 pane/카메라 열·내용 터치·busy·편집 취소·reduced motion·초점 복귀를 보호한다. 수치는 덕 구현값이다.

상태 확인 실패를 연결 해제로 보여주지 않고 최근 상태/실제계정/정상 token회전을 구분한다. 기존 인증·데이터와 전체 native Glass 계약은 보존한다. 이 웹 검사를 실제 iPhone/실계정 성공으로 확대하지 않는다.26번 이후 수정이며 새 native빌드는 별도다.

기반 Apple 캘린더 참고 · 시스템 외형 · 새 계약 우선

첨부한 Apple 월 달력과 일정 상세의 정보 구조를 참고한다. 사용자의 캘린더 제목/개인 자료가 있는 참고 스크린샷 원본은 공개 저장소에 복사하지 않는다.

년·월 선택은 캘린더 본문 오른쪽 위다. 카메라/배터리 열에 올리지 않는다.

오늘은 물리 카메라 열에서 기존 세로5탭 바로 위의 별도 원형 버튼이다. 접힘·펼침 모두 같다. 탭 바를 위로 끌어올리지 않는다.

시스템 설정에 따라 밝게·어둡게다. 기존 light 고정 정책을 대체한다. 색상을 바꾸기 위해 현재 화면/입력/편집을 재생성하지 않는다.

월 경계의 이전/다음 달 날짜는 현재 달보다 옅게 한다. 오늘·선택일은 우선 강조한다. 사용자의 “저번달과 이번달”은 인접 월 경계 날짜로 해석했으며 현재 달 전체를 흐리게 만들지 않는다.

## Duo Today·닫기

`duoTodayFrame(scene,backVisible)`는 이미 검증된 `duoTabFrame`의 마지막 안전 segment를 사용한다.

탭 바 자체는64×272pt·52pt target·28pt icon·기존 하단8pt 여백 그대로다. Today는64×64pt, radius32, 바 위8pt 간격, 요일12/16·날짜25/30이다.

좌표식: `today.bottom = safeSegment.bottom - min(segment.height,272) - 8`. x/폭은 탭 frame과 같다. back/camera/힌지/가림과 겹치는 자리에는 배치하지 않는다.

짧은 높이에서 별도 Today가 들어가지 않으면 탭 크기를 줄이거나 겹치지 않고 본문 명령줄의 오늘로 복귀한다.

등록은 pane별 id로 관리한다. 오른쪽 활성 Calendar 우선순위2, 고정 왼쪽 Calendar1. 오른쪽이 다른 탭이면 왼쪽의 Today가 동작한다. inactive/시트에서는 해당 등록을 해제한다.

닫기 경로는 실제 onClose를 등록한 원형 ×, 돌아가기 경로는 원형 ‹다. 빈 이력이나 일반 탭 선택에 임의 복귀 버튼을 만들지 않는다.

펼친 가로 왼쪽 Calendar/오른쪽 최초 Todo, 세로·접힘 현재 화면, 월·초안·스크롤 노드 보존은 유지한다. 기기 폭/모델 추정 분기나 가짜 배터리·카메라·시간 표시를 제품에 넣지 않는다. 증거의 파란 열/검은 점은 fixture 기하 표식이다.

## 서버 응답 보강·확인 범위

첨부의 “서버 응답을 읽지 못했어요”는 앱→서버 JSON 본문 파싱 경로의 일반 오류다. 공개 health/capabilities는 응답했고, 로그인 없는 Calendar API는401이다. Render의 Calendar 경로/오류 필터 결과는 빈 목록이었다. 인증된 실제 사용자 요청은 재현하지 못했으므로 해당 캡처의 정확한 운영 원인은 확정하지 않는다. 빈 로그를 정상 증거로 쓰지 않는다.

확인 가능한 코드 문제와 방어를 수정했다.

1. HTTP 헤더 수신 후 body JSON 읽기 중 AbortError가 일반 파싱 오류로 바뀌었다. AbortError를 보존해 시간 초과로 안내한다.

2. Calendar events/calendars GET은 무료 서버 기동도 고려해 전체 요청60초다. 그 외 기존 짧은15초/로그인·AI60초 경계는 유지한다.

3. Calendar GET의 비정상 JSON/HTML/잘린 body만 한 번 재조회한다. 선택한 source당 최대2회이며 대기 없는 무한 retry가 아니다. JSON으로 받은 권한 오류·401·저장/수정/confirm/OAuth 요청은 자동 반복하지 않는다.

4. 성공200이라도 items 배열/id/title·cursor 형식이 틀리면 조회 실패다. 빈 일정 성공으로 바꾸지 않는다.

5. 일부 source 실패 시 같은 owner/범위의 기존 해당 source 이벤트는 보존한다. owner/범위 변경 자료는 재사용하지 않는다. source metadata도 owner 변경 시 초기화하고 늦은 응답을 버린다.

6. 서버 `sendJson`은 JSON 직렬화 후 성공 헤더를 쓴다. 직렬화 실패라도 정상 JSON500 응답을 보낼 수 있다. 사용자 body/인증/HTML을 로그/오류에 복사하지 않는다.

7. 공개 health의 `release`는 Render가 제공한 유효한40자 공개 commit SHA만 표시한다. `calendarWorkspace:2`와 함께 배포판을 대조한다. 비밀 설정은 노출하지 않는다.
