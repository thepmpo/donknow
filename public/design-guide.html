Duo 오른쪽 세로 탭과 예약 메시지 · 2026-11-13

Duo는 본문 안쪽 오른쪽이 아니라 물리 카메라가 있는 맨 오른쪽 열에 내비게이션을 둔다. 접힘·펼침 모두 그 열 아래에 세로5개 탭, 카메라/상태 표시 아래에는 실제 복귀·닫기 경로에서만 원형 ‹를 표시한다. 상·하 안전 여백8pt,64×272pt 묶음·52pt 조작·28pt 아이콘을 유지한다. 펼친 가로 화면은 왼쪽 캘린더 고정·오른쪽 최초 Todo이며 탭 선택은 오른쪽만 바꾼다. 펼친 세로 화면과 접힌 화면은 선택 중인 화면 하나를 본문 전체에 표시한다. 회전·접힘 시 현재 탭·입력·편집·캘린더 월·스크롤을 보존한다. 일반 iPhone은 기존 하단 탭이다.

전체 네이티브 좌표에서 조작부와 본문을 분리한다. 본문에64pt 여백을 넣어 카메라 왼쪽으로 밀던 해석은 폐기한다. 분할은 Apple 힌지 상태 fullyOpen과 가로 방향에서만 켠다. 치수는 UI 토큰이며 기기 탐지 조건이 아니다. 승인 그림·새 미리보기·실기기 검수.

사용자는 내비게이션 확대와 Apple Liquid Glass·선택 이동을 승인했다. Duo는 아이콘28pt·터치52pt·세로 바64×272pt로 확대한다. native Glass는 지원하는 iOS에서만 사용하고 웹/이전OS는 블러 대체, 투명도 줄이기/고대비는 불투명 재질이다. 선택 강조판은 실제 탭 좌표로250ms 이동하고1.06배 반응하며 동작 줄이기에서는 즉시 선택한다. 빠른 탭 변경은 이전 이동을 취소한다. 일반 iPhone은 기존 하단 위치를 유지한다. 시트/본문/전체 앱 디자인을 임의로 Glass로 바꾸지 않는다. 새 미리보기·native/웹 구분·검수.

사용자가 좌우 구분선 시안을 승인했다. 펼친 가로 Duo의 실제 pane gutter 중앙에 기존 line 색 #E5E8EB·StyleSheet.hairlineWidth의 장식 선을 두고 양끝16pt를 띄운다. 스크롤/탭과 독립적으로 고정하고 터치·접근성 항목을 만들지 않는다. 세로/접힘/일반 기기/분할 비활성에는 숨기며 활성 힌지/가림과 충돌하면 중복해 그리지 않는다. 승인 원본·실제 구현·검수.

선택 Glass 정정: 이전 움직이는 파란 선택 원은 일반 색상 View였고 바 배경만 native Glass였다. 선택 표시 자체에도 지원 iOS의 GlassView regular/isInteractive를 사용하고 파란 채움을 제거한다. 글라스 부모 opacity를 낮추거나 가장자리를 잘라 깊이를 없애지 않는다. 아이콘의 선택 파란색은 유지하며 웹/이전OS는 중립 블러 대체, 투명도 줄이기/고대비는 불투명 대비 표시다. 실제 폰 재질은 수정 후 새 설치에서 검수한다. 확정 원인·빌드20·수정·검증 한계.

브리핑·날씨는 별도 화면이 기본이 아니라 설정한 시간에 덕 채팅으로 오는 메시지다. 예약은 기본 꺼짐이며 사용자가 시간·시간대·도시·자료를 정한다. 반복 AI 전송은 별도 동의, 외부 쓰기는 자동 실행하지 않는다. 작은 화면의 예약 저장은 스크롤과 분리해 고정한다. 기존 직접 조회는 오늘 내용 보기라는 보조 도구로 남긴다. 예약 동작·검증.

덕의 일상 대화 · 2026-11-12

인사·감사·잡담에는 짧고 자연스러운 존댓말로 답한다. 인사만 했는데 할 일 정보가 부족하다고 하거나 부분 조회·완료 Todo 처리 규칙을 길게 설명하지 않는다. 실제 업무 요청에는 필요한 질문과 근거를 제시하고, 확인한 범위를 넘겨 말하지 않는다. 할 일 생성과 외부 실행은 기존 확인 절차를 따른다. 실제 사용자 응답과 보완.

사용자 후속 지시로 15단계 감사의10개 항목과 편집 저장 버튼 가림을 수정했다. 수정 전후·19개 화면·검증을 현재 구현 기준으로 삼는다. 도구/자료를 접어 대화를 넓히고, 후보의 제목·날짜·확인을 메모보다 먼저 둔다. 완료는 접어서 보되 원문/실행 기록을 보존한다. 붙여넣기는 채팅으로 가져온 다음 동의하고 보낸다. 권한을 먼저 고르고 아래 연결 버튼을 누르며 연결 사실과 쓰기 승인 범위를 구분한다.

권한 행·서비스 탭·월/주·이름 편집·도구·날짜 해제는 최소44pt를 지킨다. 흰 글자의 기본 버튼 배경은 기존blue700(#1b64da)을 action 용도로 사용하며 대비는 약5.41:1이다. blue500 브랜드/아이콘, 서체·모서리·5개 탭은 유지한다. 웹 날짜 선택기는 브라우저 언어를 따르고, 확인/기기 표시는 한국어 날짜, 저장은ISO다. 할 일 시트의 저장은 본문 스크롤과 분리한다. 캘린더 선택일/내 계정 바로가기를 제공하고 작은 화면 탭은 단어 단위로 줄바꿈한다. 이는 승인된 톤·IA의 세부 조작 개선이며 전체 디자인 교체가 아니다.

공식 톤앤톤 v1.0 · 2026-11-10

승인 근거: 사용자 요청 “추천안으로 공식 확정하고 디자인 가이드와 인수인계 문서에 반영해줘”. 바로 앞 대화의 최신 추천안 A + ② + 가를 확정한다. 초기 분석 초안의 A + ① + 가 추천보다 이번 승인이 우선한다.

톤: 차분하고 친근한 비서. 짧고 담백한 존댓말로 목적·현재 상태·다음 행동을 전달한다.

역할 표시: 기본 대화 상대는 덕 하나다. 검토·설명에 필요할 때만 담당 역할을 보조 표시한다. 직원별 화면·다수 캐릭터·조직 관리를 기본 경험으로 만들지 않는다.

오리: 기존 오리를 유지하며 인사·완료 같은 의미 있는 순간에 가볍게 표현한다. 상시 움직임·게임형 사무실·새 캐릭터 자산은 이번 승인 범위가 아니다.

실행 원칙: AI는 근거와 후보를 제안하고, 사용자가 내용을 확인한 뒤 실행한다. 제안·확인 대기·실제 성공·실패·결과 불확실을 구분한다.

재사용: RP-01~RP-12를 공식 공통 원칙 v1.0으로 확정한다. 다른 프로젝트는 브랜드·색·토큰·IA를 별도 정의하며 duckduck 고유 값을 그대로 강제하지 않는다.

당시 승인은 디자인 방향·공통 원칙과 문서 반영에 한정했다. 앱 일괄 변경·Figma 교정 완료·새 수치/시안 승인·AI 직원 도구 도입을 뜻하지 않는다. 현재 코드 토큰은 유지한다. 이후 덕 채팅·Duo 적용 범위는 위 2026-11-12 지시가 우선하고, 브리핑·날씨는 후속 간략 문서 대기를 유지한다.

공식 원칙: 재사용 원칙 v1.0 · 쉬운 확정 요약 · 분석과 근거. 아래 기존 수치·동작 계약은 별도 변경 없이 보존한다.

4. 동작 규칙
