처리하는 정보와 목적

  • 이메일, 계정 식별자, 비밀번호 해시와 로그인 세션: 가입·로그인·이메일 인증·비밀번호 재설정에 사용합니다.
  • Todo 제목·메모·예정일·알림 시간·완료 기록·연결 출처: 할 일 관리·검색·내보내기에 사용합니다.
  • 승인한 외부 서비스 자료와 연결 정보: 자료 조회·선택 가져오기·확인한 수정과 발송에 사용합니다. 외부 계정 전체를 항상 읽는 것은 아닙니다.
  • AI 전송에 동의한 요청·선택 자료·필요한 대화 문맥: 답변과 작업 초안을 만드는 데 사용합니다.
  • 확인한 비서 작업의 대상·인자·상태·결과: 확인 후 실행, 중복 실행 방지와 결과 조회에 사용합니다.
  • 프로젝트 문서에 직접 남긴 이름·댓글·인용문: 공개 문의·수정 요청에 사용합니다. 댓글 본문과 표시 이름은 공개됩니다.

AI와 외부 서비스

AI가 활성화된 경우 사용자 동의를 받은 요청과 관련 자료를 OpenAI Responses API로 전송합니다. 요청에 store:false를 사용하지만 공급자의 모든 보관이 없다는 뜻은 아닙니다. OAuth 토큰과 네이버 앱 비밀번호를 모델 입력에 넣지 않습니다.

붙여넣은 원문을 앱 서버의 대화 기록 DB에 통째로 저장하지 않습니다. 사용자가 그중 일부를 Todo나 실행 초안으로 확인해 저장하면 선택한 내용은 해당 기록에 남습니다.

메일·메시지 발송, 일정·파일·페이지 수정은 실행 내용과 대상을 확인한 뒤 요청합니다. 연결 해제는 외부 서비스에 이미 저장되거나 전송된 내용을 되돌리지는 않습니다.

저장과 보호

클라우드 모드의 계정과 Todo는 서버에 연결된 DB에 저장됩니다. 배포 설정은 Render와 Turso를, 인증·재설정 메일 코드는 Resend를 사용합니다. 예약 백업은 암호화된 GitHub Actions artifact로 보관합니다. 선택적 연결은 Google·Notion·Slack·네이버·OpenAI를 사용합니다.

체험 모드 자료와 일부 설정은 기기에 저장됩니다. iPhone 로그인 토큰은 기기의 안전한 저장소를, 웹은 HttpOnly 쿠키를 사용합니다. 비밀번호는 해시로, 외부 연결 비밀값과 비서 실행 인자는 서버에서 암호화해 보관합니다. Todo 전체가 각각 암호화 저장된다는 뜻은 아닙니다.

현재 앱 코드에는 광고·행동 추적 SDK가 없습니다. 배포 사업자의 자체 보안·접속 로그와 실제 처리 국가·지역·계약·보관 조건은 최종 정책 전에 확인해야 합니다.

보관 기간

  • 계정·Todo는 사용자가 삭제하거나 탈퇴할 때까지 기능 제공에 사용합니다. 실제 적용되는 법령상 보존 의무는 최종 정책에서 확정해야 합니다.
  • 로그인 세션은 코드상 30일 후 만료됩니다. 로그아웃 시 해당 세션을, 비밀번호 재설정 시 기존 세션을 폐기합니다.
  • 비서 작업 기록은 7일이 지난 뒤 다음 기록 조회·정리 때 제거합니다. 7일 경과 순간의 예약 삭제를 보장하지 않습니다.
  • 외부 자료 임시 캐시의 가져오기 유효 시간은 10분입니다. 실제 행 삭제 시점과는 다르며 연결 해제·갱신·계정 삭제 정책을 따릅니다.
  • 인증 코드는 15분간 유효합니다. 메일 본문은 성공 후 지우며 만료한 대기 본문은 메일 작업 처리 때 정리합니다.
  • GitHub 예약 백업의 artifact 보관 설정은 7일입니다. 계정 삭제 전 생성된 백업은 개별 편집하지 않고 보관 종료로 정리합니다. 별도로 내려받은 백업과 공급자 보관 범위는 운영자가 추가 확인해야 합니다.

조회·삭제·권한 변경

내정보에서 내보내기, 연결 해제, 알림 설정, 비밀번호 재설정, 계정 삭제를 사용할 수 있습니다. 계정 삭제에는 현재 비밀번호와 명시적인 확인이 필요합니다. 운영 DB의 계정·Todo·연결과 계정에 종속된 기록을 삭제하고 공급자 권한 회수도 요청합니다. 외부 회수가 실패하면 해당 서비스 설정에서도 권한을 확인해 주세요.

iPhone의 미리 알림·알림 권한은 기기 설정에서 바꿀 수 있습니다. 가져와 저장한 Todo 사본은 권한 철회만으로 자동 삭제되지 않습니다. 앱에서 직접 삭제할 수 있습니다. 이미 보낸 메일·메시지·페이지는 해당 서비스에서 관리합니다.
