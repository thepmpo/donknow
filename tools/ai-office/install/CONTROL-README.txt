AI 사무실 업무 입력 + 휴대폰 비공개 접속

이미 사무실이 설치되고 로그인된 PC에서 사용합니다. 기존 앱/DB/키/작업을 재설정하지 않습니다.

1. 기존 2-start.cmd로 사무실 서버를 켭니다.
2. 이 ZIP을 압축 해제하고 9-open-office.cmd를 실행합니다.
3. 사무실 상단 '사무실 채팅·내 지시'를 누르고 프로젝트와 요청을 적습니다.
4. 내용을 확인한 뒤 '확인하고 실행'을 누르면 읽기 전용 검토 1건만 시작합니다.
5. 보고서가 도착하면 읽고 '보고서 확인 완료'를 누릅니다. 이는 개발/배포 승인이 아닙니다.

첫 검토가 '미결 의사결정'으로 남아 있어도 이 화면의 기존 업무 목록에서 결과를 볼 수 있습니다.
확인 완료는 검토가 성공적으로 끝났고 보고서가 변하지 않았을 때만 기록합니다.
모호한 실패는 자동 재실행하지 않습니다. 중지 버튼으로 진행 중 작업을 취소할 수 있습니다.

휴대폰에서:
1. 10-phone-connect.cmd를 실행합니다.
2. 공식 Tailscale Windows 앱 설치/본인 계정 로그인이 필요하면 화면 안내를 따릅니다.
3. 휴대폰에도 공식 Tailscale 앱을 설치하고 동일 계정으로 로그인해 연결합니다.
4. PC 창에 나오는 PRIVATE OFFICE ADDRESS를 휴대폰 브라우저에서 엽니다.
PC가 절전 상태이면 사용할 수 없습니다. 사무실과 입력 서버 창을 모두 켜두세요.

Tailscale Serve만 설정하며 공개 Funnel은 사용하지 않습니다.
기존 Serve/Funnel 설정이 있으면 임의 초기화하지 않고 멈춥니다.
HTTPS 허용 등 계정 승인은 본인이 공식 Tailscale 화면에서 해야 합니다.
Tailscale 로그인 링크/키, ChatGPT 코드/토큰, control-access.key는 채팅에 보내지 마세요.
정상 출력된 사무실 HTTPS 주소에는 일회 코드나 인증 키가 포함되지 않습니다.

이 패키지는 Linux/모의 API/모바일 브라우저/PowerShell 구문·전송 테스트를 거칩니다.
실제 Windows + 휴대폰 + Tailscale 계정 접속과 실계정 새 검토 응답은 사용자 PC에서 확인해야 합니다.
코드 수정·자동 병합·배포 기능은 잠금 상태입니다. 현재 입력은 검토/조사/제안용입니다.

업데이트: 주 사무실은 켜두고 이전 입력 서버 창만 닫은 뒤 최신 ZIP의9번을 실행합니다.
내 지시에서 요청 검색·상태별 보기가 가능합니다. 대화·추가 요청으로 이전 보고서가 도착한 업무를 이어갑니다.
기존 직원 채팅의 전송도 확인창으로 이어지며 확인 전 실행하지 않습니다.
